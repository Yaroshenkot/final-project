# TODO Планировщик задач

Веб-приложение для управления задачами с возможностью повторения.

## Выполненные задания со звёздочкой

- Правила повторения w и m
- Поиск по задачам
- Переменные окружения
- Аутентификация через JWT
- Докеризация

## Локальный запуск

go mod tidy
TODO_PASSWORD=12345 go run main.go

Открыть: http://localhost:7540

## Переменные окружения

TODO_PORT=7540
TODO_DBFILE=./scheduler.db
TODO_PASSWORD=12345

## Запуск тестов

go test ./tests

## Docker

docker build -t scheduler:latest .
docker run -d -p 7540:7540 -e TODO_PASSWORD=12345 scheduler:latest



# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.
